# 스티어링 제어 (퍼텐셜미터 피드백)

핸들과 연결된 DC모터가 기어박스를 거쳐 스티어링을 움직인다.
핸들 회전축에 달린 **퍼텐셜미터로 현재 각도를 읽어**, 목표 각도까지 모터를
구동하는 **폐루프(closed-loop) 위치 제어**다.

---

## 1. 퍼텐셜미터란 / 왜 쓰는가

퍼텐셜미터(가변저항)는 축이 회전한 만큼 저항이 바뀌는 부품이다.
3핀 중 양 끝을 5V / GND 에 연결하고, 가운데(와이퍼) 핀을 아날로그 입력에 물리면
**축의 각도가 전압(0~5V)으로 나온다.**

아두이노 `analogRead()` 로 읽으면 이 전압이 **0 ~ 1023** 정수값(ADC)으로 들어온다.

```
핸들 각도  →  퍼텐셜미터 전압(0~5V)  →  analogRead → 0~1023
```

즉 퍼텐셜미터는 "지금 핸들이 어디까지 돌아가 있는지"를 알려주는 **위치 센서**다.
이 값이 있어야 모터를 "목표 위치까지만" 돌리고 멈출 수 있다.
(센서가 없으면 얼마나 돌았는지 알 수 없어 위치 제어가 불가능하다.)

---

## 2. 배선

| 부품 | 핀 | 아두이노 |
|------|-----|----------|
| 스티어링 모터 속도 (PWM) | ENA | D11 |
| 스티어링 모터 방향 | IN1 | D12 |
| 스티어링 모터 방향 | IN2 | D13 |
| 퍼텐셜미터 와이퍼(가운데) | OUT | A0 |
| 퍼텐셜미터 양 끝 | — | 5V, GND |

- 스티어링 모터는 **2번째 모터 드라이버(L298N 등)의 A채널**에 연결한다.
- 모터 드라이버와 아두이노의 **GND는 반드시 공통**으로 묶는다.
- 모터 전원(7~12V 등)은 드라이버에 별도로 공급한다.

> ⚠️ 퍼텐셜미터의 양 끝 핀을 거꾸로 꽂으면 값이 반대로 증가/감소한다.
> 그래도 제어는 가능하나 방향 부호(`DIR_SIGN`)를 맞춰야 한다.

---

## 3. 제어 원리 (P 제어)

매 주기(약 50Hz)마다 아래를 반복한다.

```
1. actual = analogRead(A0)        // 현재 위치
2. error  = target - actual       // 목표와의 오차
3. |error| 가 작으면(DEADBAND 이내)  → 모터 정지
4. 아니면  pwm = |error| * KP       // 오차가 클수록 빠르게
            pwm 을 MIN_PWM ~ MAX_PWM 으로 제한
5. error 부호에 따라 모터 방향 결정 후 구동
```

- **오차가 클수록 빠르게, 가까워질수록 느리게** 움직여 목표에서 부드럽게 멈춘다.
- 이것이 가장 단순한 비례(P) 제어다. (필요 시 적분·미분을 더해 PID로 확장)

## 3-1. 측정된 캘리브레이션 값

`pot_read` 스케치로 실측한 값:

| 위치 | ADC 값 |
|------|--------|
| 왼쪽 최대 | 602 |
| 중립 | 526 |
| 오른쪽 최대 | 424 |
| 중립 유격(백래시) 폭 | 50 (≈ ±25) |

- **오른쪽으로 갈수록 값이 작아진다** (좌 602 → 우 424).
- 중립 526은 좌우 중앙(513)보다 약간 왼쪽 → 가동범위 비대칭(좌 +76 / 우 −102).
- 유격 폭이 50이므로 `DEADBAND`를 **25(±)** 로 잡아 백래시 구간 내 떨림을 막는다.

→ `steering_test.ino` 에 `POT_LEFT=590`, `POT_RIGHT=440`, `DEADBAND=25` 로 반영함
(끝단 602/424 안쪽으로 여유를 둬 기계적 한계 충돌 방지).

## 4. 조정 파라미터

`steering_test.ino` 상단에서 수정한다.

| 상수 | 의미 | 조정 가이드 |
|------|------|-------------|
| `POT_LEFT` / `POT_RIGHT` | 좌/우 목표 ADC 값 | **반드시 실측**(아래 5단계) |
| `DEADBAND` | 정지 허용 오차 | 떨리면 키우고, 부정확하면 줄임 |
| `MIN_PWM` | 최소 구동 PWM | 안 움직이면 키움 |
| `MAX_PWM` | 최대 PWM | 너무 거칠면 줄임 |
| `KP` | 비례 게인 | 느리면 키우고, 진동하면 줄임 |
| `DIR_SIGN` | 방향 반전 | 반대로 폭주하면 0↔1 |

## 5. 테스트 순서

1. **업로드 후 캘리브레이션**
   - 시리얼 모니터(115200)를 연다.
   - 핸들을 손으로 좌 끝 / 우 끝까지 천천히 돌리며 `actual` 값을 확인한다.
   - 그 범위 **안쪽** 값으로 `POT_LEFT`, `POT_RIGHT` 를 수정한다.
   - (끝단에 모터가 밀어붙이면 과열·손상되므로 여유를 둔다.)

2. **방향 확인**
   - 목표를 줬을 때 모터가 **목표 쪽으로** 가는지 본다.
   - 반대로 점점 멀어지며 폭주하면 `DIR_SIGN` 을 `0`→`1` 로 바꾼다.

3. **부드러움 조정**
   - 목표에서 좌우로 떨리면 → `DEADBAND` ↑ 또는 `KP` ↓
   - 너무 느리게 도달하면 → `KP` ↑ 또는 `MIN_PWM` ↑
   - 도달 시 덜컹거리면 → `MAX_PWM` ↓

테스트 스케치는 3초마다 목표를 좌↔우로 자동 전환하며,
`target / actual / error` 를 시리얼로 출력한다.

---

## 6. 주의 / 한계

- **퍼텐셜미터 회전 범위**: 일반 단권 포텐셔미터는 약 270°만 돈다.
  핸들/스티어링이 그보다 많이 돌면 다회전(multi-turn) 타입을 쓰거나
  기어비로 범위를 맞춰야 한다.
- **기어박스 유격(백래시)**: 퍼텐셜미터가 핸들축에 있으므로,
  기어 유격만큼 실제 바퀴 각도와 미세한 오차가 생길 수 있다.
  정밀도가 더 필요하면 피드백 센서를 스티어링 출력축으로 옮긴다.
- **부호 불일치 = 폭주**: 모터 정방향이 ADC 값을 키우는 방향이어야 한다.
  반대면 오차가 계속 커지며 끝단으로 밀어붙인다 → `DIR_SIGN` 으로 교정.
